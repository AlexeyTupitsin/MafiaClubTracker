# Инструкция по развёртыванию MafiaClubTracker

Это руководство позволяет любому клубу спортивной мафии поднять собственную копию приложения с нуля. Навыки программирования не требуются — только браузер.

**Что потребуется:**
- Аккаунт [GitHub](https://github.com) (бесплатно)
- Аккаунт [Supabase](https://supabase.com) (бесплатно)
- Аккаунт [Vercel](https://vercel.com) (бесплатно)
- ~1 час времени

---

## Шаг 1 — Создать копию репозитория

1. Открыть страницу репозитория на GitHub
2. Нажать зелёную кнопку **"Use this template"** → **"Create a new repository"**
3. Заполнить:
   - **Repository name** — например `mafia-tracker` (любое название латиницей)
   - **Visibility** — выбрать `Private` (рекомендуется)
4. Нажать **"Create repository"**

> Если кнопки "Use this template" нет — нажать **Fork** в правом верхнем углу.

---

## Шаг 2 — Создать проект в Supabase

1. Зайти на [supabase.com](https://supabase.com) → **"Start your project"**
2. Нажать **"New project"**
3. Заполнить:
   - **Name** — название проекта, например `mafia-club`
   - **Database Password** — придумать и сохранить пароль (понадобится позже)
   - **Region** — выбрать ближайший к вам (для России: `Frankfurt (eu-central-1)`)
4. Нажать **"Create new project"** — подождать ~2 минуты пока проект создаётся

---

## Шаг 3 — Создать структуру базы данных

1. В Supabase Dashboard слева выбрать **SQL Editor**
2. Нажать **"New query"**
3. Выполнить SQL-файлы из папки `sql/` репозитория **по порядку** (001, 002, 003...):
   - Открыть файл на GitHub, скопировать содержимое
   - Вставить в SQL Editor
   - Нажать **"Run"** (Ctrl+Enter)
   - Убедиться что в правом нижнем углу написано "Success"
   - Повторить для следующего файла

Порядок выполнения:
```
sql/001_initial_schema.sql
sql/002_profiles.sql
sql/003_audit_log.sql
sql/004_storage.sql
sql/005_rls.sql
sql/006_indexes.sql
sql/007_auth_config.sql
sql/008_season_threshold.sql
sql/009_player_avatar.sql
sql/010_best_move.sql
```

---

## Шаг 4 — Настроить аутентификацию в Supabase

1. В левом меню выбрать **Authentication** → **Providers**
2. Найти **Email** → убедиться что включён
3. **Важно:** отключить "Confirm email" (иначе при регистрации будет требоваться подтверждение email):
   - Authentication → **Configuration** → Email
   - Переключить **"Confirm email"** в положение OFF
4. Нажать **"Save"**

---

## Шаг 5 — Получить ключи Supabase

1. В левом меню выбрать **Project Settings** (значок шестерёнки внизу)
2. Перейти в **API**
3. Скопировать и сохранить в отдельный файл (блокнот):
   - **Project URL** — выглядит как `https://xxxxxxxxxxxxxxxx.supabase.co`
   - **anon public** ключ — длинная строка начинающаяся с `eyJ...`

> Это секретные данные вашего проекта. Не публикуйте их открыто.

---

## Шаг 6 — Задеплоить на Vercel

1. Зайти на [vercel.com](https://vercel.com) → **"Sign Up"** (или войти)
2. Выбрать **"Continue with GitHub"** — авторизовать Vercel в GitHub
3. На главной странице Vercel нажать **"Add New..."** → **"Project"**
4. В списке репозиториев найти ваш (например `mafia-tracker`) → нажать **"Import"**
5. На странице настройки проекта:
   - **Framework Preset** — должен определиться как `Vite` автоматически
   - **Root Directory** — оставить пустым (`.`)
   - Найти раздел **Environment Variables** — здесь вставляем ключи (следующий шаг)

---

## Шаг 7 — Добавить переменные окружения в Vercel

В разделе **Environment Variables** на странице деплоя добавить четыре переменные:

| Name | Value |
|------|-------|
| `VITE_SUPABASE_URL` | Project URL из шага 5 |
| `VITE_SUPABASE_ANON_KEY` | anon public ключ из шага 5 |
| `VITE_CLUB_NAME` | Название вашего клуба, например `БольшаяМафия` |
| `VITE_CLUB_CITY` | Ваш город, например `Москва` |

Для каждой переменной:
1. Вписать имя в поле **Name**
2. Вписать значение в поле **Value**
3. Нажать **"Add"**

**Логотип и иконки:**

Лого в интерфейсе, favicon во вкладке и иконки приложения берутся из файлов в папке `public/`. Чтобы поставить свои — см. Шаг 10 ниже.

---

## Шаг 8 — Запустить деплой

1. Нажать **"Deploy"**
2. Подождать 1–3 минуты пока идёт сборка
3. Vercel покажет ссылку вида `https://mafia-tracker-xxx.vercel.app`
4. Открыть ссылку — должна появиться страница входа в приложение

---

## Шаг 9 — Создать первого администратора

1. В Supabase Dashboard → **Authentication** → **Users**
2. Нажать **"Add user"** → **"Create new user"**
3. Заполнить:
   - **Email** — формат `имя@mafia.local`, например `admin@mafia.local`
   - **Password** — придумать пароль
4. Нажать **"Create user"**
5. Назначить роль администратора — в **SQL Editor** выполнить:
   ```sql
   UPDATE profiles SET role = 'admin' WHERE id = (
     SELECT id FROM auth.users WHERE email = 'admin@mafia.local'
   );
   ```
6. Зайти в приложение с этими данными

---

## Шаг 10 — Заменить логотип и иконки на свои

Лого в интерфейсе, favicon во вкладке браузера и иконки PWA берутся из файлов в папке `public/`. Чтобы поставить свой бренд, замените эти файлы своими — **обязательно с теми же именами**:

1. На GitHub открыть ваш репозиторий → папку `public/`
2. Нажать **"Add file"** → **"Upload files"**
3. Загрузить свои файлы с теми же именами:
   - `logo.jpg` — логотип в интерфейсе и favicon во вкладке (квадратный, минимум 192×192px)
   - `icon-192.png` — иконка PWA 192×192px (установка на телефон)
   - `icon-512.png` — иконка PWA 512×512px
4. Нажать **"Commit changes"** — Vercel автоматически передеплоит

---

## Шаг 11 — Изменить название в PWA (необязательно)

Если хотите чтобы при установке приложения на телефон отображалось ваше название:

1. На GitHub открыть файл `public/manifest.json`
2. Нажать значок карандаша (Edit)
3. Изменить строки:
   ```json
   "name": "НазваниеВашегоКлуба — Спортивная мафия",
   "short_name": "НазваниеКлуба",
   "description": "Учёт игр спортивной мафии. ВашГород."
   ```
4. Нажать **"Commit changes"**

## Добавление пользователей

Чтобы добавить игроков/зрителей:

1. Supabase → **Authentication** → **Users** → **"Add user"**
2. Email формата `ИМЯ@mafia.local`, придумать пароль
3. По умолчанию роль `viewer` (могут смотреть, но не редактировать)
4. Для второго администратора — выполнить SQL из Шага 9

Передать пользователю: ссылку на сайт + его email + пароль.

---

## Обновление до новой версии

Когда разработчик выпустит обновление:

1. GitHub → ваш репозиторий → вкладка **"Sync fork"** → **"Update branch"**
2. Vercel автоматически подхватит изменения и передеплоит

## Частые вопросы

**Сколько это стоит?**
Бесплатно. Supabase Free tier: 500 МБ БД, 1 ГБ хранилища. Vercel Free tier: без ограничений для личных проектов. Для клуба ~30 человек этого хватает на годы.

**Можно ли использовать свой домен?**
Да. В Vercel → Settings → Domains → добавить домен. Нужно купить домен (~500–1000 ₽/год).

**Данные двух клубов не смешаются?**
Нет. У каждого свой Supabase-проект — полностью изолированные базы данных.

**Что если что-то пошло не так?**
- Проверить вкладку **Deployments** в Vercel — там есть логи ошибок
- Проверить правильность ключей в Environment Variables
- Убедиться что все SQL-файлы выполнены успешно
